# Logi-View

Open-source logistics process intelligence for visualizing operational flows, required and optional bookings, capacity, queues and bottlenecks.

## Current scope

- Interactive order-to-shipping process map
- Required, optional and automated booking steps
- Capacity, queue and cycle-time indicators
- Bottleneck and duplicate-booking signals
- Baseline/optimized scenario comparison
- Responsive desktop, tablet and mobile workspace

## Technology

Next.js 16, React 19, TypeScript 5.9, Tailwind CSS 4, React Flow 12 and Cloudflare-compatible Vinext.

## Development

```bash
pnpm install
pnpm dev
```
